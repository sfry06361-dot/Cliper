# ClipCraft (كليب كرافت)

تطبيق أندرويد لفحص روابط الفيديو وتنزيلها، استخراج اللقطات المهمة بالذكاء الاصطناعي (`Gemini 3.8 Flash`)، رفع الجودة والدقة، تعديل الوقت، وكتابة التفاصيل والنصوص على الفيديو.

## طريقة تنزيل ملف التطبيق الجاهز للتثبيت (APK)

### الطريقة الأولى (الأسرع من داخل المنصة مباشرةً):
اضغط على قائمة الإعدادات في أعلى منصة **AI Studio** واختر **Generate APK** ليتم تنزيل ملف التثبيت مباشرةً على جهازك.

### الطريقة الثانية (من GitHub):
1. لا تضغط على ملفات الكود أو ملف `.yml` لأنها تعرض الكود فقط.
2. بعد رفع المشروع لـ GitHub عبر **Push to GitHub**:
   - افتح قسم **Releases** في الصفحة الرئيسية للمستودع على GitHub وستجد ملف **`ClipCraft.apk`** جاهزاً للتنزيل بضغطة واحدة.
   - أو افتح تبويب **Actions** بالأعلى ← اختر **Build ClipCraft APK** ← حمّل **`ClipCraft-APK`** من قسم **Artifacts**.
